# 项目简介
本项目针对精准农业中的物理除草需求，设计并实现了一套基于嵌入式AI的智能激光除草机器人系统。系统以瑞芯微RK3588高性能处理器为核心计算平台，深度融合计算机视觉与实时控制技术。通过部署经TensorFlow训练、转换并量化为RKNN格式的YOLOv8目标检测模型，实现对田间作物与杂草的实时识别与精准定位。上层应用基于Qt框架构建，采用多线程池、流水线并行与硬件解码等优化策略，在保证检测精度的前提下，稳定达到80~90 FPS的实时推理性能。系统创新性地融合“目标检测+绿色语义分割”双重判定策略，精确锁定非作物区域的杂草，并通过MODBUS协议将目标坐标下发至单轴激光控制器，完成非接触式、高精度的物理除草作业。整机系统兼具高实时性、高可靠性与良好的工程可推广性。

# 功能特性
**1.模型部署与异构计算优化**
采用TensorFlow训练YOLOv8检测模型，利用tf2onnx工具将模型转换为ONNX中间表示，再通过RKNN-Toolkit适配并量化为适合RK3588 NPU加速的RKNN模型。该部署流程在保证模型精度的同时，充分发挥了NPU的算力优势，为实时推理提供底层支撑。

**2.嵌入式多线程并行推理架构**
基于Qt框架设计并实现高性能控制软件，引入线程池与生产者-消费者队列，构建流水线并行处理结构。将图像采集、硬件解码、推理计算与结果显示解耦，最大化利用RK3588的多核CPU与NPU资源，确保系统在80~90 FPS的高负载下稳定运行。

**3.双重判别策略提升除草精度**
系统并非单纯依赖目标检测，而是采用“YOLOv8识别农作物 + 绿色语义分割”的组合策略。首先通过检测模型定位农作物区域，再结合颜色特征分割出绿色植被，最终通过逻辑差分锁定非农作物区域的绿色杂草，有效降低了误杀率，提升了除草的选择性。

**4.硬件解码与数据流优化**
针对海康威视网络摄像机，利用FFmpeg集成MPP硬件解码单元，实现H.264/H.265码流的零拷贝硬解码。解码后的帧数据通过线程池管理，分别推流至推理线程与界面显示线程，实现了数据的高效分发与低延迟渲染。

**5.精准运动控制与通信协议**
系统将识别出的杂草目标坐标，通过MODBUS-RTU/TCP协议实时下发至单轴激光控制器，控制激光束精确指向杂草位置完成瞬时灭杀，实现了视觉引导与运动控制的高效闭环。
